# Données collectées

## Données non personnels collectées
L'application collecte en amont des données issus des librairies partenaires permettant l’identification personnelle.
- Le nom de la librairie.
- Son addresse.
- le code postal.
- La ville.
- Le chiffre d'affaire annuel.
- La date de partenariat.
- La spécialité associée à la librairie.

## Données personnelles collectées

L'application collecte en amont certaines données sensibles lors de la récupération des librairies partenaires  permettant l’identification personnelle.
Les données collectées sont :
- Le prénom et nom du contact propriétaire de la librairie.
- L'email du propriétaire de la librairie.
- Le numéro de téléphone du propriétaire de la librairie.

Ces données sont collectées uniquement avec le consentement explicites des responsables des librairies partenaires.

## Traitement des données

Toutes les données collectées sont traités en amont avant d'être sauvegardé dans une base de données. Les informations sensibles n'ayant pas eu de consentement explicite ou n'étant pas destinés à aucun traitement seront supprimées.
Les données à caractères sensibles seront supprimées avant d'être sauvegardé dans une base de données.
Ces données auront pour but de répertorier les librairies partenaires ainsi que leur geocode.  

## Protection des données
Toutes les données sont enregistrées dans une base de données sécurisé. Comme la loi le permet, ces données sont soumis a des règles strictes (Par exemple Droit à l'oubli...) Avec un responsable, Thierry.


## Suppression des données
Chacun peut exiger que ces données soient supprimer, pour cela plusieurs façon possible:
- Remplir le formulaire de contact ou envoyer un email au responsable des traitements de données Thierry à l'addresse thierry@ecf.Fr et indiquer les informations voulant être supprimées.
